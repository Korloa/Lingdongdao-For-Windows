# 灵动岛

Windows 11 屏幕顶边的小型灵动岛。空闲时显示一条短线；有提醒时从短线展开，默认 3.5 秒后收起。

## 使用

从 [Releases](https://github.com/Korloa/Lingdongdao-For-Windows/releases/latest) 下载 `LingDongDao-Setup-…exe` 安装版，或下载 `LingDongDao-portable-…zip` 解压即用版。两者均内置运行所需的 .NET。默认按 **Ctrl+Alt+D** 打开控制面板，也可以右键点击任务栏通知区的灵动岛图标打开。面板中的四组快捷键（控制面板、图片格式、风格、压缩）都可点击输入框后直接按组合键修改；若与其他程序冲突，可从托盘菜单打开面板更换。鼠标沿屏幕顶边移到短线位置，或直接贴近短线，都会自动展开；移开后收起。触发区大小可在面板调节。复制图片后默认按 **Ctrl+0/1/2** 分别打开格式、风格、压缩选择条；选择期间灵动岛不会自动收起。

控制面板提供三种显示模式：**自动切换**（默认，收到提醒时展开）、**保持展开**（持续显示充电样式预览）、**完全隐藏**（顶边短线也隐藏，仍可用快捷键或托盘打开面板）。外观可分别调节短线长宽、展开宽高、顶部距离、圆角、内容留白、图标和文字大小、背景透明度、动画速度与停留时间。图片操作选择条可调节可视项数（格式 3 或 5 项）、每项宽度、间距、文字字号和横向滚动时长；缩略图圆角、悬浮大图尺寸和短线鼠标触发区也可调节。短线悬浮展开可以单独关闭。每项都能拖动滑块，或在右侧输入精确数值并按回车；调整时即时预览，取消或关闭面板会恢复已保存的外观。默认展开高度为 **68 px**，允许调至 60–110 px；宽度允许调至 220–420 px。提醒开关、触发阈值、开机自动启动和四组全局快捷键也可在面板中设置。托盘右键菜单也能直接切换开机启动。开机自动启动默认关闭，开启后在当前用户登录 Windows 时运行；移动程序文件后需要重新开启。点击“保存并应用”后重启仍会保留；“恢复默认”需再点击保存。配置文件位于 `%LOCALAPPDATA%\LingDongDao\settings.json`。

## 提醒

- 电源：接入电源时显示充电状态和电量；未接电且电量低于阈值时提醒，默认阈值为 20%。
- 剪贴板：复制文本时显示开头，复制图片或图片文件时显示带圆角的方形缩略图；悬浮缩略图会在灵动岛下方显示放大后的图片。鼠标在放大图上滚动可缩放预览。右下角的编辑按钮会展开画笔、截图/裁剪、压缩、风格、撤回、取消和完成工具；截图/裁剪用于框选当前图片的局部区域。取消不会修改剪贴板，点击“✓ 完成”才会把编辑后的图片与文件放入剪贴板。普通预览不写入磁盘。
- 图片转换：复制图片后按 **Ctrl+0**，格式条并排显示 **SVG、PNG、JPG、GIF、BMP** 五项；用 **A/D** 或鼠标悬停滚轮让文字匀速横向滚动一格并吸附到中间，超出可视边界的内容会裁切。滚动期间的重复输入不会积压成后续滑动。按 **Enter** 或点击格式即转换并复制，按 **Esc** 退出。转换后的文件保存在 `%LOCALAPPDATA%\LingDongDao\Converted`，同时把文件和图片放入剪贴板，可在资源管理器中粘贴为对应格式文件。旧转换文件会在后续转换时清理。SVG 是嵌入原位图的 SVG 文件，不会把像素自动描摹成矢量路径；JPG 不保留透明度。
- 图片风格：复制图片后按 **Ctrl+1**，横向选择 **艳丽、高冷、黑白、扫描**；确认后生成 PNG，图片和文件一同放入剪贴板。扫描是高对比度灰度效果。
- 图片压缩：复制图片后按 **Ctrl+2**，横向选择 **<200KB、200–500KB、500KB–1MB、1–2MB、2–5MB** 中上限小于当前图片大小的档位；没有更小档位时会提示。复制图片文件时使用文件的实际大小；剪贴板只有位图时用 PNG 编码大小作比较。确认后生成 JPG，按所选档位的上限压缩，必要时缩小尺寸。透明区域会填为白色，提示中会显示实际文件大小。放大预览中的压缩工具也使用相同的档位筛选。
- 音乐卡片：网易云音乐或酷狗音乐播放时显示歌名、歌手和来源，提供上一首、播放/暂停、下一首按钮和播放进度。播放期间保持展开，暂停后按普通提醒时间收起；悬浮顶边短线可重新打开。先读取 Windows 系统媒体会话，支持时可点击进度条跳转；播放器没有提供会话时，网易云从本地播放状态读取进度，酷狗尝试从进程读取进度，进度条只显示而不可拖动。酷狗进度读取依赖播放器版本，无法读到时隐藏进度。其他提醒可暂时覆盖卡片，结束后恢复。播放器更新可能改变本地状态格式或快捷键；托盘“查看检测状态”可查看当前识别结果。
- Wi‑Fi：连接新网络时显示网络名称；链路速率连续两次低于阈值时提醒，默认 30 Mbps；已连接但连续两次无法访问网络时提醒。链路速率是网卡协商值，不是下载测速结果。
- 内存：占用率连续三次达到阈值时提醒，默认 85%；低于阈值 5 个百分点后可以再次提醒。
- 温度：CPU 或 GPU 温度连续两次达到阈值时提醒，默认分别为 90°C 和 88°C。温度来自 LibreHardwareMonitor；没有可用传感器时跳过。
- 郫都区雷雨：默认每 30 分钟查询一次成都市郫都区附近的未来 24 小时逐小时预报，出现雷雨天气代码时弹出提醒。同一时段运行期间不重复提醒；可在面板中关闭或调整查看范围（6–48 小时）。数据来自 Open-Meteo 天气预报，仅供参考，并非官方气象预警；查询失败时可在托盘“查看检测状态”中查看原因。

Wi‑Fi、内存、温度约每 10 秒检查一次，网络连通性约每 30 秒检查一次。托盘菜单可预览提醒、查看检测状态或退出程序。

## 源码运行与构建

需要 Windows 和 .NET 9 SDK：

```powershell
dotnet run --project .\LingDongDao\LingDongDao.csproj
```

生成独立可执行文件：

```powershell
dotnet publish .\LingDongDao\LingDongDao.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:DebugType=none -o .\dist
```

安装版由 `installer/LingDongDao.iss` 使用 Inno Setup 7 编译；安装到当前用户的应用目录，无需管理员权限。便携 ZIP 包含独立 EXE 和本说明文件。

检测本机可用的 Wi‑Fi、网络、内存和温度数据：

```powershell
dotnet run --project .\Diagnostics\Diagnostics.csproj -c Release
```
